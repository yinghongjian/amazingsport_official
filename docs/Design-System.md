## 3. 设计规则

### 3.1 Token 层级与候选色板

实施时分为基础值、语义 Token、组件状态，不把散落的十六进制色值写满组件。此处是设计规则，尚未建立业务 Token 模块。

| 语义 | A 雪域极简 | B 科技精密 | C 少年运动时装 |
|---|---|---|---|
| surface/base | #F6F6F2 | #EDF0ED | #F5F1EB |
| surface/photo | #D2DADD | #CDD5D7 | #DAD9E0 |
| surface/section | #F0F2EF | #193446 | #E3DCEF |
| text/primary | #193446（正文可 #191B1E） | #193446 | #302348 |
| text/on-dark | #F6F6F2 | #F6F6F2 | #F5F1EB |
| border/subtle | #CBD2D3 | #B7C2C6 | #C9C0D3 |
| accent/brand（候选） | #71608D | #71608D | #5B4788 |
| focus | #5B46A1，深色底改为浅色外框 | 同左 | 同左 |

浅色分隔线只用于装饰分组，不承担唯一边界或交互状态；可操作控件的边框/焦点要单独满足对比度。强调色不能无条件用于小号文本。配色比例是整页 UI 面积预算而非每个屏幕机械比例；图片自然色不计入。

### 3.2 字体与授权路径

| 用途 | 正式候选 | 静态稿实际调用 |
|---|---|---|
| 中文（A/B/C） | Noto Sans SC 400/500，C 标题可 600 | 本机 PingFang SC；没有打包或分发系统字体文件 |
| A 拉丁 | Manrope 400/500 | Avenir Next / Helvetica Neue 系统回退 |
| B 拉丁/短索引 | IBM Plex Sans 400/500；IBM Plex Mono 400 | Helvetica Neue / 系统 monospace |
| C 拉丁 | Manrope 500/700 | Avenir Next / Helvetica Neue 系统回退 |

已核查的字体来源均为 SIL OFL 1.1 文本：[Noto Sans SC](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt)、[Manrope](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt)、[IBM Plex](https://github.com/IBM/plex/blob/master/LICENSE.txt)。正式接入时下载明确版本、保存许可证和版权通知，按条款处理子集/修改与保留名称；本轮没有引入外部字体网络依赖或认定本机系统字体可任意重新分发。

中文字体文件较大，正式实施评估所需字重/子集及自托管策略；不让字体下载阻塞首屏。更换为正式字体后重新拍照比较换行、数字宽度、菜单和按钮，不能把回退字体效果称为正式字体验收通过。

### 3.3 字阶、网格与间距

字号 / 行高单位 px；桌面指 1280–1440，手机指 375–390。768 平板采用中间值并以文字实际容纳为准。

| 层级 | A 桌面 / 手机 | B 桌面 / 手机 | C 桌面 / 手机 |
|---|---|---|---|
| HERO | 64/77 · 40/48 | 62/74 · 40/48 | 76/87 · 36/43 |
| 大章节 | 38/55 · 28/41 | 46/60 · 32/44 | 46/62 · 32/44 |
| 小标题 | 24/36 · 22/33 | 24/36 · 22/33 | 24/36 · 22/33 |
| 正文 | 16/30 · 16/28 | 16/29 · 16/28 | 16/30 · 16/28 |
| 字段/链接 | 13–14/22 | 13–14/22 | 13–14/22 |
| 非关键英文索引 | 11–12/18 | 11–12/18 | 11–12/18 |

画板部分手机标签 10px，仅作视觉索引，不放证据限定、尺码或必读信息。正式站必要说明至少 14px，不能用小字规避事实范围。标题字距 -0.02～-0.04em 为起点；静态稿局部为构图使用更紧字距，正式中文字形需逐行审核；正文正常字距，英文大写短标签可 0.08～0.14em。正文阅读宽度通常 28–36 个汉字，最大约 670px。

| 项目 | 桌面 | 平板 | 手机 |
|---|---|---|---|
| 栏数 | 12 | 8 | 4 |
| 外边距 | 64；1280 可 48 | 32 | 24；375 必要时 20 |
| 沟槽 | 24 | 20 | 12–16 |
| 章节距离 | A 96–128 / B 80–96 / C 80–104 | 64–80 | 48–64 |
| 内部间距 | 8/16/24/32/48/64/96/128 的有限阶梯 | 同尺度缩减 | 不以随机数填空 |

桌面无强迫每个模块都左右对称。A 单主图与长留白；B 规则线和信息秩序；C 受控错位。手机不保留拥挤的桌面排版，优先单列与完整衣身。

### 3.4 组件语言与必要状态

| 组件 | 共用原则 | A / B / C 区分 | 实施时状态要求 |
|---|---|---|---|
| 页眉 | Logo 及五项主导航；不加假购物袋/账号/语言开关 | A 浅底；B 深蓝实底；C 暖纸 | 默认/当前页/滚动/菜单打开；键盘焦点清楚，不能 hover 才可访问 |
| 主 CTA | 每个 HERO 只有一个主要动作；高≥48px，文字与目的地匹配 | A 细框；B 深蓝实底；C 墨紫实底 | default/hover/focus/active；未配置入口用说明，不放假按钮 |
| 次级链接 | 动词清楚、有下划线或独立辨识方式 | A 细线；B 与章节索引对应；C 自然句子 | 颜色不能作为唯一可识别特征 |
| 产品编辑卡 | 图+名称/版本+一个实际差异；不显示虚构价格/库存 | A 大图少款；B 有序目录；C 服装比例与色彩节奏 | 图片加载/失败/配色缺图；列序与形象选图分离 |
| 配色/尺码 | 色名文字 + 实际图；尺码依据到具体款 | 全方向保持同一信息纪律 | 选中/不可用/未提供区分；不伪造库存和智能推荐 |
| 产品证据区 | 对象、结论、限制、来源、日期在相邻位置 | A 留白短文；B 标签/规则线；C 回到安静纸面 | 无证据内容不上线；过期撤回；来源无公开权时仅有获批摘要 |
| 指南阅读 | 问题标题→直接回答与边界→步骤→相关产品 | A 舒展；B 分节有序；C 轻快标题但正文克制 | 可在初始 HTML 阅读；不以全部折叠隐藏核心答案 |
| 移动菜单 | 正式实施支持开关、焦点管理、Escape、背景滚动控制 | 三案只改变表面颜色和字重 | 当前画板只画文字标签，不声称菜单已实现 |

画板中的产品信息行是明确标注的内部样式样本，无假参数。不能直接搬到线上充当商品详情。真正的产品卡与参数表需在阶段 3/4 的已核验数据上验证。

### 3.5 摄影、素材与动效

- 本轮使用原图 CSS contain 或排版定位，未删除水印、重绘服装或改色。完整原图来自 PPT，可通过资产 manifest 追溯。
- A 主体在右、文字在左，手机改上文下图；B 左图右文，手机先文后图；C 三幅错位，手机两幅。摄影是版面核心，不能把它降为装饰缩略图。
- 当前高分辨率图仍是嵌入资源，未完成生产格式、压缩、响应式源集、版权及 SKU 映射审核；静态画板的加载体积不能代表上线性能。
- 单次入场上限：透明度 + 8px 内位移；A 300ms、B 180–220ms、C 250ms。hover 120–160ms。没有自动轮播、滚动劫持、视差或长时间 pin。静态画板未执行这些动效。
- 减少动效时立即显示全部内容，无位移、平滑滚动或自动视频；视频必须有真实静帧、静音及暂停机制，非首屏必要依赖。
- 保留自然年龄、姿态与服装比例；不以成人极限户外、大量奖章、金色光效或虚构实验换取“高级感”。

### 3.6 GEO 与内容真实性（保留前置要求）

品牌/商品/指南关键信息是可见文本，不只存在于图片、Canvas、动画结束或爬虫特供版本。图片 Alt 描述可见产品与动作，不灌入“最轻”“领导”等未经审核称号。

具体款式身份、来源、适用条件与审定日期一起展示；每个来源链接能关联回对应产品。样式中“资料依据”仅为内部字段示意，正式页面必须替换真实内容或删除模块。

首页仍以摄影和主张为先。指南与证据在系列、详情和科技中可达，手机正文单列，限制条件不缩小为难读脚注。产品、图库中的裤装外观与“软壳裤”商品身份分开，不以穿搭图片替代 SKU 核验。

- 字体许可路径已核查；正式字体渲染、真实菜单、动效、业务 CTA、站点性能和 AI 收录均未验证。
- 品牌确认方向后，将选定方案收敛为唯一语义 Token 与组件规范，再在阶段 3 只实现首页；本轮不自动进入开发。

## 视觉方向确认（2026-10-30）

**目标：**以 A「雪域极简」作为主方向，吸收 B 的技术信息排版方式。

**上下文：**用户已明确确认此组合。本记录取代此前“方向待确认”的状态；三案静态稿保留为评审档案。

**约束与执行：**整体配色、主字体、字阶、网格、导航、HERO、摄影及留白沿用 A。B 仅贡献技术章节的信息组织：清晰字段、对齐、细分隔线，以及参数、适用款式、来源和审核日期的关联；不套用 B 的整套深蓝页眉或 HERO。手机采用纵向信息行，避免宽表横向溢出。C 保留为参考。正式 Logo、素材授权、具体文案和产品参数仍按项核验，商品发布顺序保持不变。

**验收：**品牌章节保持 A 的视觉节奏；技术信息逐款可追溯、手机可读；全站同一语义只采用一个默认 Token。本次仅同步文档，不修改静态画板或业务代码，阶段 3 尚未开工。

## 阶段 3 首页实施（2026-10-30）

- 目标：实现 A 雪域极简 + B 技术信息排版的响应式首页，限定首页九个章节，不创建业务内页。
- 上下文：用户已授权阶段 3，并确认温区分类“轻暖、中暖面包、御寒、极寒”，系列/属性“雪花泡芙、云壳系列、校服神器运动鹅绒”。这是两个维度；极寒没有核验款式时展示真实空状态，不编造温度。
- 约束：无既有应用，采用 Astro + TypeScript + 原生 CSS，静态 HTML、内容数据解耦、少量交互脚本；相较 Next.js，本期无需 React 运行时或服务端业务，后续可增量扩展静态内页。依据 https://docs.astro.build/en/concepts/why-astro/ 与 https://docs.astro.build/en/guides/typescript/ 。只本地预览，不部署。
- 文件范围：src/、public/、scripts/、package.json/锁文件、Astro/TypeScript/ESLint 配置；docs/Asset-Replacement.md 与 docs/Homepage-QA.md。原始素材及阶段 2 画板保留。
- 素材：本轮新提供的 161×85 Logo 用于原型，保持比例；照片仍需发布授权。没有核验购买 URL 时显示说明，不制造空按钮；所有主导航与 CTA 使用真实首页锚点。无视频时使用图片。
- 验收：lint/typecheck/build；五宽度浏览器检查；菜单键盘与焦点、分类及空状态、场景切换、减弱动效、图片失败回退；至少 1440 与 390 全页及首屏截图。正式资料、主体、授权和购买链接未齐前不宣称可上线。

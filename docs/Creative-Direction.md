# 奇动 AMAZING SPORT：三种视觉方向

日期：2026-10-30｜阶段 2 评审稿｜A 主方向已确认，吸收 B 技术信息排版

## 1. 目标

建立国际高端运动时装的视觉体验，同时清楚表达奇动的少年人群、鹅绒核心品类和产品信息。三个方向需要在构图、阅读节奏、摄影关系上可区分；不以更换背景颜色充当三个概念。

推荐 A「雪域极简」作为官网主方向，吸收 B 的证据表达纪律；C 可作为未来穿搭故事的专题语言。此组合现已由用户确认。

## 2. 上下文与共同边界

1. 保留当前 PRD 的品牌定位与用户编辑，不借视觉提案改写商业定位。宣传称号、首创、奖项和技术性能的具体发布范围依原事实矩阵，不能因视觉强调而扩大。
2. 鹅绒服发布优先级按 PPT 首次出现顺序；形象产品编辑选图不等于改变产品列表顺序。羊毛 T 恤、软壳裤属于搭配补充，首屏不改成综合服饰商城。
3. 六张附图所示产品的形象角色已经确认。蓝、绿、深色图在 PPT 中找到高分辨率嵌入素材；紫色正背面找到较清晰嵌图。原样引用，不生成新服装、场景或测试效果。
4. 第 3 张城市图有“豆包 AI 生成”标记，本轮三案不使用它作为主视觉或真实场景依据；形象款角色仍保留。其他图的权利和拍摄来源仍需最终核验。
5. 尚无正式 Logo 源文件，画板的 AMAZING SPORT 与奇动是明确标注的名称排版占位，不是新设计字标，也不替代现有手写/图形 Logo。
6. 素材目前以竖幅棚拍为主。A 以棚拍光线和版面表达冬季冷静感，没有用假雪山拼接伪装品牌实拍；横版雪地大片属于下一步拍摄/交付需求。
7. 未访问或复制 Moncler、Goldwin、Arc'teryx 的页面、摄影、商标与独特布局。方向基于本项目的摄影与信息需求独立推导。

## 3. 三个概念

### A｜雪域极简 · Editorial Alpine（已确认主方向）

**关键词：轻盈、舒展、少年。**

**故事线：**冬天不是把少年包进厚重的外壳，而是让衣服进入他们自己的步调。从一张能看清服装和身体状态的安静形象照开始，经过短宣言，再走近产品、工艺与日常穿法。这里的“轻盈”首先是视觉与品牌意图，不替代商品实测结论。

**Moodboard 文字定义：**阴天散射光、蓝灰色棚拍背景、浅蓝服装、干净的雪白纸面、冷色山地晨光的拍摄意向；不出现成人登顶英雄叙事。纸面没有纹理滤镜，摄影保留织物真实明暗。品牌紫色仅作为非常少量的连接点，等待 VI 审核。

**配色（UI 色面预算，不包含照片本身，合计 100%）：**

| 角色 | 色值 | 比例 |
|---|---|---|
| 主背景 Snow White | `#F6F6F2` | 60% |
| 摄影承托 Mist | `#D2DADD` | 18% |
| 正文 Graphite | `#191B1E` | 10% |
| 标题/重点 Deep Navy | `#193446` | 6% |
| 辅助 Glacier | `#BFD6E0` | 4% |
| VI 衔接候选 Violet | `#71608D` | 2% |

**字体、网格与间距：**中文 Noto Sans SC 400/500，拉丁 Manrope 400/500。HERO 桌面 64/77px、手机 40/48px；章节 38/55 与 28/41；正文 16/30 与 15–16/28；辅助英文 12/22，手机 10–11/18（装饰标签，非关键正文）。桌面 12 栏、左右 64px、沟槽 24px；正文常用左右 6/6 或 5/7。章节间距 96–128px；手机 24px 边距、4 栏、48–64px 章节距离。大标题中文字距约 -0.03em，正文 0；不拉大每个中文字做奢侈感。

**图片与人物：**使用用户图 4 对应蓝色形象款，身体自然直立，眼神稍离镜头，保留袖口、下摆与靴子；青少年气质先于成人时装姿态。图 6 的绿色半身作为下方对照。不靠大面积雪峰压小人物；正式户外拍摄需让服装占据可辨识的视觉面积，环境只建立气候与情绪。

**HERO 静帧草案：**1440 宽中，页眉高 88px；左 48% 为留白文字，右 52% 为完整竖幅照片与冷灰承托。标题左对齐，短英文一行，主 CTA 位于文字下方；图内不叠参数和奖章。右下小图注是内部评审提示，不属于正式商品页。

**移动裁切：**375/390 宽改为文字在上、竖图在下，先看到标题与 CTA；图用 contain 保留头、衣服与下摆，不机械裁成桌面横图。静态稿图高约 470px；实际阶段 3 根据视口高度检查首屏节奏，不为了“一屏塞满”把衣服缩成小图。未来横版原片与手机竖片保持同款、同色、同叙事。

**交互语言（设计规格，静态稿不执行动效）：**浅色页眉，滚动后变为实底；有摄影背景时用独立浅底保障可读，不用浓黑渐变。章节单次透明度渐显，300ms、位移不超过 8px；无视差、无滚动劫持。按钮方角或 2px 微圆角、细边线、48px 以上高；hover 可反白。产品卡为大图+名称+一行款式差异，去掉卡片底板和阴影，不显示虚构价格。材质用真实近摄与短文，对应“查看依据”文本链接，先阅读再展开说明。

### B｜科技精密 · Precision Performance

**关键词：清晰、秩序、可信。**

**故事线：**先看见服装轮廓，再追问每个设计选择。让父母能知道“这是什么款、信息从哪里来、适用什么范围”，通过信息组织建立可信感。科技感来自有依据的解释，不来自更多数字。

**Moodboard 文字定义：**设计工作室的样衣观察、深蓝色资料封面、克制的索引编号、整齐的规则线、哑光织物与缝线；无 HUD、荧光、电路、假实验室或 3D 纤维模型。绿色产品形成物质感，与冷色信息区相互制衡。

**配色（UI，不计照片，100%）：**`#EDF0ED` 48%（纸面），`#193446` 32%（深蓝标题/深色章节），`#B7C2C6` 12%（分隔及承托），`#68784F` 6%（橄榄辅助），`#71608D` 2%（品牌连接）。橄榄色仅色块与图注，不作小号正文底。

**字体、网格与间距：**中文 Noto Sans SC 400/500；拉丁 IBM Plex Sans 400/500；索引/经确认参数用 IBM Plex Mono 400，等宽字仅限短字段。HERO 62/74 与 40/48；章节 46/60 与 32/44；正文 16/29；字段 13–14/22。12 栏，外边距 64，沟槽 24，8px 基线；信息行 16px 上下 padding；分隔线 1px。手机边距 24，4 栏，信息表每行标签 78–80px，其余给内容，不强塞横向大表。

**图片与人物：**图 6 对应绿色形象款作为产品观察，突出领口、门襟和绗缝关系。保留正常人物比例和原片光线；不要画科学测量线假装研究结果。后续可拍真实工艺近摄，但当前主视图不是面料微观证据。

**HERO 静帧草案：**左 54% 完整照片、右 46% 为结构化文字；上方细线与章节编号，中部中文标题，下方单个 CTA。顶部深蓝页眉形成稳定框架。编号只代表章节，不能与温度、测试成绩混淆。

```text
[ 深蓝页眉：品牌名称                   导航 ]
[                      | DESIGN / 01 —— ]
[ 绿色形象款产品视图    | 把设计，         ]
[ 领口 / 衣身轮廓      | 落在细节里。     ]
[                      | 解释文本 / CTA   ]
[                      | 品牌 / 品类索引  ]
```

**移动裁切：**文字先于照片，去掉装饰性大索引，保持全幅静态视图；背景不铺细网格。参数一行一事，条件紧跟数值，不用横向滑动仪表盘。证据主体在 HTML 正文，折叠只收纳扩展信息。

| 中文主标题 | 英文副标题 |
|---|---|
| 把设计，落在细节里。 | DESIGN IS IN THE DETAILS. |
| 看清每一层，选对每一件。 | LOOK CLOSER. CHOOSE WITH CLARITY. |
| 少年的衣服，认真到细节。 | EVERY DETAIL, CONSIDERED FOR YOUTH. |

静态稿使用第一组。第二组“每一层”只能用真实结构图/照片配合，不授权虚构剖面；第三组中的细节是设计意图，不暗示未经证实的人体工学研究。

**交互语言：**页眉始终实底；章节锚点直接抵达内容。展开资料 180–220ms，支持立即展开的减少动效模式。按钮深蓝实底，hover 轻微明度变化，无发光。产品卡像编辑目录：图片、款式/代际、适用场景，不做表盘。技术模块“问题→结构→依据→适用款”，线条帮助扫描，不装饰成精密仪器。禁止数字滚动、自动对比胜负、合成温度变化。

### C｜少年运动时装 · Youth Fashion Motion

**关键词：自主、节奏、玩心。**

**故事线：**从少年喜欢的穿着形象进入，颜色、廓形与动作一起表达“自己的节奏”。随后把造型连接到具体款式和清楚的选码信息。家长得到判断依据，少年保有审美自主。

**Moodboard 文字定义：**校外城市步行、运动后短暂停留、淡紫纸面、杂志接触印样般的前后视图、深色鹅绒与红色裤装的服装对比。不是幼儿卡通，也不是成人夜店运动时装；不使用涂鸦字体、贴纸、促销爆炸符号。

**配色（UI，不计照片，100%）：**`#F5F1EB` 48%（暖纸），`#E3DCEF` 26%（淡紫），`#302348` 16%（墨紫文字），`#5B4788` 8%（VI 连接/少量实底），`#D9564A` 2%（有限红色强调）。紫色不是已确认 VI 的精确复刻；最终需与正式手册色值对齐。照片里的红色裤装不计入 UI 比例。

**字体、网格与间距：**中文 Noto Sans SC 500/600；拉丁 Manrope 500/700。HERO 76/87 与 36/43，中文不斜体、不描边；章节 46/62 与 32/44；正文 16/30；短标题可用 24/36。桌面 12 栏、外边距64、沟槽24；图片采用约 4/5/3 比例、第二张下移 35px，偏移有规则。章节间距 80–104px；手机边距24、图片间距12，双幅构图，不出现自动滚动跑马灯。

**图片与人物：**图 1/2 对应浅紫正背面与图 5 对应深色全身是形象组合。保留自然站姿、微转身和少年年龄感；裤装色彩用于节奏，但不能据图认定这条裤子就是已确认软壳 SKU。正式拍摄可补自然步行/转身/同伴互动，拒绝成年人性感或攻击性姿态。

**HERO 静帧草案：**上方大中文标题，右侧英文与 CTA；下方三张错位照片分别呈现正面、搭配、背面。它是形象编辑组合，不是产品排序列表，因此不会把形象款调到商品发布队列首位。

**交互语言：**页眉暖纸实底；最多一个章节一次 250ms 轻微入场，错位来自静态排版而非飞入。按钮墨紫实底、2px圆角；hover 小幅色阶变化。产品卡按服装比例展示，名称与款式信息留白充足，无悬浮促销贴纸。科技区从形象色退回安静纸面，仍用证据链接和逐款信息；没有俏皮图形替代事实。手机无横向滚动劫持。

### 3.4 三案评分与取舍

以下是本轮设计判断，不是用户测试结果。独特性/一致性/高级感/移动体验：5 表示更优。**开发复杂度：1 最简单、5 最复杂，越低越易维护**；不相加计算总分，也不假装客观排名。

| 维度 | A | B | C |
|---|---|---|---|
| 独特性 | 4：蓝色形象款与少年留白叙事有识别度，但必须靠正式摄影避免普通极简模板 | 4：款式—证据关系让科技表达具体，失去摄影会偏资料站 | 5：紫色与正背面错位组合更鲜明，仍需正式字标建立品牌专属感 |
| 品牌一致性 | 4：契合轻暖与探索，但弱化当前紫色表达，需要品牌接受这一转译 | 4：契合科技面料诉求，需避免显得成人装备化 | 4：延续紫色及年轻穿搭，但需控制视觉热闹程度 |
| 高级感 | 5：留白、主体尺度和少量文案最适合品牌提升；依赖高质量原片 | 4：秩序清楚，但线条与标签过多会像产品手册 | 4：时装感较强，但图片数量与色彩必须克制 |
| 移动体验 | 5：单主体、单列过渡，裁切风险最低 | 4：信息更密，需持续控制表格与说明长度 | 4：双幅手机构图更难处理，小屏必须减少图片 |
| 开发复杂度 | 2：标准图文布局和少量状态即可完成；摄影准备成本另计 | 3：证据、版本、信息表的关系与状态较多 | 3：错位栅格和多端图片选择需要更多检查，禁止以复杂动效补救 |

推荐：采用 A 的整体节奏，延用 B 的“看见依据”信息样式，C 保留为故事专题候选。若品牌认为紫色识别应更强，可先在 A 的小比例 VI 连接与形象素材中调整；不直接把三个 HERO 拼成一页。

## 4. 验收与方向确认

### 4.1 本轮检查范围

三案均包含：桌面 HERO、手机专门排版、产品/证据样式、手机指南片段。实际浏览器检查包括五种宽度 1440/1280/768/390/375、图片加载、全页横向溢出、画板内锚点与浏览器错误；结果与限制见 [阶段 2 检查](../design/stage-2/QA.md)。

画板不实现正式菜单/产品筛选/购买渠道，不代表官网业务验收；动效只定义，不以静态稿宣称动效通过。系统字体排版可检查，但正式部署字体替换后必须重新验字距和换行。

### 4.2 素材交付优先级

- A：蓝色形象款横版原片/同场景竖片、可留中文标题的安全区、真实冬季生活方式组图。
- B：绿色形象款原片、对应款式真实领口/面料/缝线微距、可公开的规格与证据摘要；不做假技术图。
- C：浅紫正背面高分辨率原片、深色形象款原片及同龄人自然动作照片。
- 三案共同：正式 Logo 源文件/VI、模特与摄影授权、SKU/色号对应。现有 PPT 高分辨率嵌图改善设计验证，不自动证明授权或拍摄来源。

### 4.3 需要品牌选择

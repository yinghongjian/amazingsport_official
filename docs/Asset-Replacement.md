# 首页素材与事实替换清单

阶段 3 内部原型，2026-10-30。`src/data/home.ts` 管理分类、款式、场景及购买配置；`src/data/assets.json` 记录原图哈希与派生尺寸。`public/images` 仅为按比例缩放的 WebP 与用户 Logo，未改色或生成新服装。

## 范围说明

款式索引呈现手卡中有明确名称的 16 款，含鹅绒马甲；不重复加入身份不明的图片页，不改变完整发布队列。校服款以用户新增属性归类，温区未知时不猜测。分类名称不是具体温度保证。无销量、评分、绝对轻量、奖项或认证的虚构陈述。

正式图片替换优先沿用组件的宽高比例与 alt，重新生成 responsive 源集并进行裁切检查。购买链接核验后只通过数据配置接入，不将私有报告直接打包到公开目录。

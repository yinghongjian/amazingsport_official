## 3. 约束：事实审核与素材交付

### 3.1 状态规则

- **已发现：**文件存在；不含真实性、权利或发布许可判断。
- **已读取：**能够定位具体内容；仍可能是内部草稿或宣传。
- **待品牌核验：**缺对应 SKU、来源、方法、权利、有效期或审定记录；统一标记 `[待品牌核验]`。
- **可发布：**仅在责任人确认事实、限定范围、资产权利和最终文案后设置。本轮没有替品牌批准任何商品参数或宣传称号。
- **过期/撤回：**停止对外主张，并检查图片、Alt、摘要与结构化数据是否同步撤下。

品牌提供的正式逐 SKU 签核资料可以成为证据；并非所有普通事实都必须有第三方报告。涉及性能、比较、产地、奖项、市场地位等内容，证据必须与实际主张强度和适用范围相称。

## 4. 验收与后续维护

### 4.1 资料进入页面的检查

1. 每个公开主张有事实 ID、来源及定位、适用产品范围、审定人/日期；原始证据与发布摘要分开。
2. 每张图关联资产 ID、适用 SKU/场景及权利状态，图片里的字也受审核约束。

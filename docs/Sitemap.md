# 站点地图与导航方案

版本：0.2｜2026-10-30｜阶段 1 + GEO 规划稿，路由尚未实现

## 1. 目标

让首次访客建立品牌认知，让家庭从款式进入可核查的产品信息，让已有购买意图的人快速找到真实官方渠道。所有设备共用信息架构；细节要求以 [PRD](PRD.md) 为准。

## 2. 上下文

当前目录只有项目指令，没有网站应用或既有 URL，因此下列是待批准的路由方案，不是可访问链接。域名、首发商品及文章 slug 未确定，不创建虚构网址。

### 2.2 分类方案（等待 D02）

首选以品牌真实企划分类，辅助以穿着场景说明差异。候选标签为“轻暖”“中暖”“御寒/厚暖”，其中“御寒”如何映射“厚暖”尚未批准。未确认的分类不出现在页面或 SEO 中。

雪花泡芙是系列名称候选，4.0/5.0/Ultra/旗舰等应核定层级；同货号不同版本在内部必须有不同产品键。云壳双面穿是否进入首发另由 D02 决定。马甲、校服搭配款只有列入真实货盘时才出现；网球、防晒、游泳、滑雪作为后续专题，不创建空导航。

不要将年龄直接作为尺码分类；不要按未经验证温区建立筛选；不要把大码自动归为成人款。

## 3. 约束

### 3.1 导航与响应式

| 区域 | 桌面 1280/1440 | 平板 768 | 手机 390/375 |
|---|---|---|---|
| 页眉 | Logo；鹅绒系列、核心科技、品牌世界、探索故事、购买渠道 | Logo + 菜单；宽度足够才展开 | Logo + 有可访问名称的菜单按钮 |
| 全局菜单 | 五项一级导航，无多层大菜单 | 展开菜单完整呈现五项 | 同一顺序，购买渠道不藏在第三层；可关闭、可返回焦点 |
| 首页 HERO | 大图与留白文字区，一个主 CTA | 优先保持衣服与人物构图 | 专门图片或独立焦点；不把人物头部/衣服主体截断 |
| 系列内导航 | 可见的分类标签 / 章节导航 | 触控可达；不得只支持 hover | 分类可换行，或有明确横向滚动提示；不带动整个页面溢出 |
| 产品详情 | 图片与信息分栏，尺码信息易发现 | 视内容改为上下布局 | 多图顺序阅读；购买入口可固定但不遮内容和键盘焦点 |
| 长内容 | 适度阅读宽度；可有章节目录 | 保持正文可读，不强制窄边栏 | 单列；目录折叠不隐藏正文；表格只允许容器内横滚 |
| Footer | 简短品牌语、系列/品牌/故事/渠道、隐私/主体信息 | 顺序一致，可分组 | 紧凑分组；必要联系和政策链接不依赖复杂折叠 |

断点取决于实际内容是否容纳，不用设备名称硬编码另一个信息体系。设计采用桌面 12 栏、平板建议 8 栏、手机建议 4 栏；字号、间距和最终断点留阶段 2 审定。

### 3.2 导航行为

- Logo 始终回首页；当前页面可识别，键盘焦点不因透明导航而消失。
- 移动菜单打开后焦点进入菜单，Escape/关闭按钮可退出；关闭返回触发按钮；背景不被误滚动。
- 锚点进入章节时为页眉留出空间，浏览器返回行为合理；减弱动效偏好时不用平滑滚动作为必需条件。
- 页面链接以链接元素实现，局部展开以按钮实现；不使用 `href="#"` 充当未完成动作。
- 产品配色/分类应反映实际数据，已选状态可恢复；不会造成成百上千个无内容 URL。
- 外部购买链接标清平台及目的地；无需自动弹 App 或下载；扫码不是手机唯一选择。

### 3.3 阶段 3 首页原型的临时边界

阶段 3 只实现首页，不偷做完整内页。原型中的系列、科技、品牌、故事和渠道导航可以进入首页同名真实章节，按钮用“查看系列章节”等匹配动作的文字。已经有真实官方渠道时可外跳；未核实时明确为内部占位说明，不呈现可点击的购买按钮。

这是一项供阶段 3 批准的原型方案，不是把锚点当作已完成内页。阶段 4 完成页面后替换为正式路由，并在验收中逐条验证。完整 P0 发布不允许留下原型占位。

### 3.4 内容与 SEO 路由治理

- slug 稳定且唯一，不依赖短期宣传名或价格；代际变更、货号复用由内部 ID 区分。
- 正式页面使用真实 canonical；域名未批准时保留配置缺口，不部署示例域名。
- 图片 Alt 描述可见服装/动作，不能塞入未经核验技术词和搜索关键词。
- sitemap 只列可访问、可索引的已发布路由；robots 不替代访问控制。
- 筛选、追踪参数的 canonical/noindex 策略在实现时统一；正文重复的组合不独立索引。
- 若以后英文上线，需要完整译文、审校、对应路由及互相正确的语言关系；P0 不展示假语言切换。
- 下架但有有效知识内容的产品可保留说明；失效链接提供已核实替代；永久迁移才用针对性重定向，不能把未知路径统统重定向首页。

## 5. GEO 路由增补（2026-10-30，v0.2）

本节增加 GEO 修订版 P0 页面，补充 §2.1 路由树；原路由不删除。页面规格见 [GEO 架构 §3.2](GEO-Architecture.md)。新增路由仍未实现。

```text
/guides                       G01 选购指南中心
/guides/{slug}                G02 单一决策主题的指南
/evidence                     E01 已批准公开证据索引
/evidence/{slug}              E02 单一报告/资料主题的说明
```

| 来源页 | 新增出口 | 回流与转化 |
|---|---|---|
| 首页系列章节、系列页、Footer | 指南中心和重点指南 | 指南 → 匹配款式 → 官方渠道 |
| 产品详情的适用场景/尺码 | 对应指南 | 保留明确的产品详情返回入口 |
| 产品详情/科技/品牌的具体主张 | 对应证据说明 | 证据 → 关联产品/科技，不强制下载 PDF |
| 指南 | 支持论点的证据、对应商品 | 无证据或无合适款时不硬推荐 |
| 证据索引 | 实际已批准的证据条目 | 无获准公开内容时不生成空索引 |

桌面/平板/手机仍使用五项主导航；指南在系列入口和 Footer 可见，证据靠对应主张上下文链接。首页不增加密集 FAQ。首发指南 slug 候选：choosing-kids-goose-down、school-layering、compare-goose-down、size-and-fit；需内容批准后才生成实际 URL。

一个意图只维护一份权威正文；同义问题用同页小节覆盖，不生成近重复页面。公开证据以 HTML 摘要为主体，可选附获授权原件。PDF 附件的索引/规范策略在部署时确定，内部资料绝不通过 robots.txt 充当保密措施。

本次新增 G01/G02/E01/E02 的文档规格已完成；实际导航、索引、抓取与转化均 NOT TESTED。

## 1. 目标

### 1.1 产品使命与定位

建立以品牌形象为首、帮助家庭理解鹅绒服产品价值并进入真实官方渠道的品牌官网。品牌体验达到国际高端运动时装的审美标准；“国际高端”是本项目的体验目标，不代表品牌产地、国际市场地位、奢侈品资质或价格调整。

**定位：超轻鹅绒服，当然奇动 中国儿童超轻鹅绒服领导品牌 奇动amazing sport，雪花泡芙®️超轻鹅绒服开创者 奇动，专注为5到16岁儿童和亲子/青少年提供科技面料，舒适结构，更高质价比的潮科技运动服饰品牌

主线：**看见少年穿着的状态 → 理解轻暖设计的理由 → 找到适合的款式 → 核对尺码、护理与证据 → 前往官方渠道。**

差异化来自可验证的组合：儿童与青少年真实穿着、明确的冬季产品聚焦、款式级材料与结构解释、克制而有青春感的摄影。现阶段不宣称这些能力具有行业唯一性。

### 1.2 目标优先级与成功信号

| 优先级 | 目标 | 观察方式 | 不可误读为 |
|---|---|---|---|
| 1 | 建立奇动的品牌识别与高级感 | 品牌方视觉评审；访谈能识别品牌、人群、主打品类 | 自动化工具已经证明品牌高级 |
| 2 | 让家长理解产品差异 | 能从详情找到该款规格、尺码及来源；完成选款任务 | 看见 800 蓬就代表全系列都是 800 蓬 |
| 3 | 让少年认可穿着形象 | 能找到校园、城市、轻户外穿着内容 | 所有年龄、体型都适配同一版型 |
| 4 | 官方渠道转化 | 合格的渠道外跳、对应商品落地路径可达 | 站内点击等于成交 |
| 5 | 稳定、可访问、易维护 | 页面与交互验收、性能测量、内容更新演练 | 单次实验室测试等于线上真实用户表现 |

首轮建议做 6–8 组家庭的任务访谈，覆盖下述年龄段及手机使用；需另行安排与获得参与授权，不属于本轮已完成工作。目标是每位参与者能说清品牌和主打品类，能完成“找款—看尺码—去官方渠道”。记录具体失败点，不用小样本夸大转化结论。上线前不承诺销量提升幅度。

### 2.2 受众：使用者、影响者与付款者

以下是产品设计假设，不是已完成的用户调研结论。

| 受众 | 角色与主要任务 | 需要看见 | 体验要求 |
|---|---|---|---|
| 5–8 岁儿童 | 穿着者；由父母主导选款，儿童表达颜色与舒适偏好 | 清楚的衣服、真实动作与日常穿法 | 图像直观，避免成人化姿态；不以复杂参数说服儿童 |
| 9–12 岁儿童 | 穿着者、共同选款者 | 校园搭配、活动状态、颜色与廓形 | 有运动感，避免幼儿化卡通与玩具风 |
| 13–16 岁青少年 | 穿着者、较强的审美决策参与者 | 同龄气质、版型细节、城市与轻户外穿搭 | 尊重独立审美，避免把所有少年当作小童 |
| 父母及监护人 | 主要付款者、质量与售后判断者 | 产品对应规格、尺码、护理、证据、官方渠道 | 信息可查、文字可读，购买路径短 |
| 亲子家庭 | 共同穿着与搭配决策 | 经确认的大码及亲子同款关系 | 不把“有 180 码”自动等同于成人版型适合 |

网站不要求输入儿童生日、姓名、学校或身体数据。尺码选择使用经审核的静态尺码表，不建立儿童用户档案。

### 2.3 信息层级与品牌故事

1. **品牌识别：**奇动 AMAZING SPORT、少年形象、冬季鹅绒服。一句主张与一个主要 CTA。
2. **穿着利益：**衣服在校园、城市与日常探索中的穿法和设计意图；不把“轻暖”扩写为极端温区保证。
3. **产品选择：**品牌审定的系列结构、款式、颜色、尺码、场景。
4. **可信解释：**材料、结构、工艺与该款证据；区分设计说明、实测和第三方结论。
5. **品牌世界：**设计哲学、真实团队与内容；奖项和市场地位作为支持信息。
6. **行动：**了解该款 → 官方渠道；已有购买意图的人可从主导航直接进入渠道页。

叙事建议：“少年需要自在探索的冬天”作为情绪起点，以真实服装在身体上的状态建立愿望，用材料和工艺细节回答家长的问题。正文中文优先，英文只作为经审校的品牌辅助语，不强行逐段双语。

阶段 2 可评审用户给出的三组标题。“轻若无感”等表达仍为创意候选，不能自动成为实测或性能承诺。本轮不确定最终 slogan。

### 2.4 访问者旅程与关键转化

| 入口 / 意图 | 建议路径 | 关键疑问 | 失败时的替代路径 |
|---|---|---|---|
| 第一次了解品牌 | 首页 → 系列 → 详情 → 官方商品页 | 奇动是谁？孩子是否喜欢？这款有何不同？ | 详情可回系列；找不到款式时到渠道说明 |
| 内容吸引 / 少年共同选款 | 故事 → 文中对应款式 → 详情 → 分享页面 URL 给家长 | 这套穿搭是哪一款？ | 无可售关联款时保留故事，不做假商品链接 |
| 家长搜索产品信息 | 搜索落地详情 → 尺码 / 护理 / 科技依据 → 渠道 | 能否穿合适？参数是否对应？ | 官方店铺或经核实的客服入口 |
| 关注质量与技术 | 科技页 → 适用款式 → 对应详情 → 渠道 | 哪些是事实？验证条件是什么？ | 未发布主张不显示；不要用另一款报告代替 |
| 已知品牌 / 复访 | 主导航购买渠道 → 官方店铺或指定产品 | 哪个入口是真的？ | 浏览器链接兜底，二维码只作为补充 |
| 亲子穿搭 | 首页生活方式 / 故事 → 有亲子尺码的款式 → 详情 | 成人与儿童是否同款、是否有合适尺码？ | 不满足时只保留搭配内容，不承诺亲子全码 |

建议事件词典：`view_collection`、`view_product`、`open_size_guide`、`open_evidence`、`view_story`、`outbound_channel_click`。仅在分析工具与数据收集方案获批后启用；参数限页面、款式 ID、内容 ID、渠道、设备大类，不记录儿童信息。合格渠道外跳率分母为进入产品详情或渠道页的会话，分子为至少一次有效官方外跳的会话；去重规则、排除内部流量方式在上线前定义。第三方店铺成交不可由网站自行推算。

## 3. 约束与范围

### 3.1 分期

| 范围 | 内容 | 进入条件 |
|---|---|---|
| P0 MVP | 中文响应式首页、系列列表、详情模板与已核实首发款、科技、品牌、故事列表与详情、购买渠道、404、必要的隐私/法律信息；真实链接；基础 SEO、无障碍、图片优化 | PRD 和视觉批准；发布素材与内容审核完成 |
| P1 | 完整英文版本、更多故事与影片、更多已确认款式、可用的对比/站内搜索、经批准的分析工具、较完整线下门店信息 | 明确需求与维护责任；有足够内容、资源和可验证收益 |
| P2 | 网球/防晒/游泳/滑雪等季节专题、更丰富内容合作、业务确需时评估 CMS 或服务集成 | 单独立项、成本与数据方案批准 |
| 当前不建设 | 站内支付、购物车、会员、积分、库存/订单/ERP、大型 CMS、评论系统、强制订阅与弹窗 | 不因 P2 到来而自动开发，必须重新论证 |

P0 是完整官网的首发范围，跨阶段 3–6 实现；不等于阶段 3 一次实现全部页面。建议先核验 3–6 个有清晰差异的款式；这是工作量建议，最终数量由品牌决策 D02 确认。

### 3.2 页面规格

下列 title 与 description 为 SEO 草稿；“官网/官方”须在品牌主体、域名与渠道归属确认后使用。实际路由见 Sitemap。每页一个主要 H1；正文、图片文字、Alt、OG 与结构化数据适用同一事实审核规则。

#### H01 首页 `/`

- **目标：**一眼认识品牌与少年鹅绒服，进入系列并理解品牌主线。
- **模块顺序：**极简导航 → 全屏 HERO → 品牌宣言 → 旗舰鹅绒系列 → 科技章节 → 校园/城市/雪地/亲子生活方式 → 工艺细节 → 品牌世界（内含一则探索故事入口）→ 购买渠道 → Footer。采用用户本次指定的首页顺序。
- **关键信息：**真实品牌字标、主打产品、经确认的系列名、设计利益及对应证据。轻暖/中暖/厚暖只是待确认分类，不自动套用温区。
- **交互：**移动菜单、锚点/路由导航、轻微渐显、静态首屏回退；视频为可选增强，能暂停、默认静音、不阻塞阅读。移动端独立图片或构图裁切。
- **CTA：**HERO 唯一主要 CTA“探索鹅绒系列”→ `/collections/goose-down`；章节次级“了解核心科技”“阅读故事”；底部“查看购买渠道”→ `/where-to-buy`。
- **SEO：**title「奇动 AMAZING SPORT｜少年鹅绒服与运动生活」；description「认识奇动 AMAZING SPORT，探索鹅绒服系列、产品设计与少年运动生活，查阅款式信息和购买渠道。」OG 使用已授权主视觉。
- **验收：**首屏不混入促销及未经核验数字；1440/390 的产品主体与主标题均完整；所有 CTA 目标已实现或在首页原型阶段使用真实可达的同页章节；不链接未实现的空白路由。首页原型不能据此视为完整站点通过。

#### C01 鹅绒系列 `/collections/goose-down`

- **目标：**把款式差异讲清楚，让家庭做初步选择。
- **模块顺序：**系列开篇大图 → 分类说明 → 编辑式产品展示 → 场景穿法 → 选择/尺码提示 → 渠道。
- **关键信息：**已发布款式名、版型、颜色、场景、款式专属卖点；轻暖/中暖/御寒的映射经品牌确认。没有证据时不显示量化温区、排行和“最暖”。
- **交互：**P0 只提供有真实数据的分类切换；选中状态可分享并在返回时恢复；零结果提示与清除筛选；内容少时用章节导航，无必要不增加筛选器。
- **CTA：**“了解这款”→ `/products/{slug}`；“查看选码说明”进入对应详情，不做一套尺码表覆盖全部。
- **SEO：**title「鹅绒服系列｜奇动 AMAZING SPORT」；description「浏览奇动鹅绒服的款式、版型与穿着场景，了解对应产品的材质、尺码和设计细节。」过滤组合不生成重复索引页。
- **验收：**每张产品图、名称和目标详情匹配；不同版本不合并参数；分类可用键盘与触控操作；返回后不丢失用户选项。

#### P01 产品详情 `/products/{slug}`

- **目标：**完成选款判断，明确可核对的规格、尺码、护理与购买目的地。
- **模块顺序：**面包屑 → 产品多视图及名称/版本 → 产品故事与版型 → 配色/尺码 → 材料与工艺 → 已核实参数与依据 → 场景 → 护理 → 对应官方渠道 → 少量相关款。
- **关键信息：**独立款式 ID、货号、季节/代际、配色；参数带单位和适用范围；尺码表区分成衣尺寸与人体建议；充绒量按尺码；温区与机洗只在该款证据完整时呈现。品牌确认前不公开手卡达播价、预售价、售后口头承诺或库存。
- **交互：**缩略图/大图、可访问的放大查看；色名与图片同步；尺码表折叠或对话框；证据说明；手机购买条不遮正文和系统安全区。配色未有图时不伪造换色，显示真实可用视图与说明。
- **CTA：**有直接对应商品 URL 时“前往官方店铺查看此款”；只有店铺链接时明确“前往官方店铺”并展示可复制货号；链接未核实时内部预览标注 `[待配置]`，不提供伪按钮。
- **SEO：**title「{已核实款式名}｜奇动 AMAZING SPORT」；description 按该款版型、场景及已核实事实生成；独立 canonical 与 OG。Product 结构化数据仅含已发布事实；没有真实价格/库存时不伪造 Offer、评价或 AggregateRating。
- **验收：**相邻版本、色号不串图；尺码与参数逐款核验；移动端能完整读表；每个购买链接匹配款式或明确是店铺；未发布款式不进入索引及导航。

#### T01 核心科技 `/technology`

- **目标：**以材料与工艺解释设计，回答“为什么这样做”。
- **模块顺序：**设计问题 → 已授权材料微距 → 鹅绒与面料章节 → 结构/缝制细节 → 验证方法与限定条件 → 对应款式。
- **关键信息：**每条主张有 claim ID、适用款式、资料来源与审核日期；区分原料测试与成衣测试。只讲已确认内容；“DenseAir”名称、大小写与商标标记均待正式规范。
- **交互：**章节导航、真实前后细节查看、证据说明展开、适用款式链接；不做虚构 3D 层结构、模拟温度计或自动生成的实验效果。
- **CTA：**“查看采用此设计的款式”→ 已过滤且有内容的系列页或确切详情。
- **SEO：**title「材料与工艺｜奇动 AMAZING SPORT」；description「了解奇动鹅绒服的材料选择与工艺设计，查阅适用款式及相关说明。」未经核实不把参数写入关键词或摘要。
- **验收：**每条技术结论能回溯证据；样本、测试条件、适用范围不被折叠成不可发现的小字；普通手感视频不被称为实验结论。若没有可发布的技术内容，本页保持内部预览并阻止完整 MVP 上线验收，或由品牌批准缩减范围。

#### B01 品牌世界 `/brand`

- **目标：**解释奇动为何为少年做运动服饰，形成可信、持续的品牌认知。
- **模块顺序：**品牌主张 → 服务的人与真实场景 → 设计哲学 → 产品方法 → 经确认的团队/创始人故事 → 经核验的荣誉与范围 → 探索故事。
- **关键信息：**品牌名称与授权字标、年龄范围、设计意图；团队履历、合作关系及奖项分别审定。高端视觉目标不改变既有品牌“质价比”定位，是否对外保留该词由 D01 决定。
- **交互：**短章节阅读、可访问的荣誉来源说明、故事链接；不堆砌证书墙。
- **CTA：**“走进探索故事”→ `/stories`；辅助“探索鹅绒系列”。
- **SEO：**title「品牌世界｜奇动 AMAZING SPORT」；description「了解奇动面向儿童与青少年的设计理念，以及关于校园、日常与探索的品牌故事。」Organization 数据仅填核实的主体、Logo、URL 与官方账号。
- **验收：**不把品牌手册视为代言授权；不把不同产品的奖项全部归于雪花泡芙；市场地位用语保留原证据的范围与来源，不变成全品类第一。

#### S01 探索故事列表 `/stories`

- **目标：**用持续的穿着和设计内容延展品牌，提供产品以外的访问理由。
- **模块顺序：**一篇重点故事 → 编辑式文章列表 → 场景/设计主题导航（有内容才出现）→ 关联系列。
- **关键信息：**真实标题、摘要、封面、发布日期、文章类型；P0 建议先准备 2–3 篇有素材与审稿人的文章。不将新闻、广告转载、设计手记混成新闻背书。
- **交互：**真实文章链接；内容较少时不用分页；以后分页保留明确 URL。没有文章时内部预览说明缺口，不发布假日期或虚构采访。
- **CTA：**“阅读故事”→ `/stories/{slug}`。
- **SEO：**title「探索故事｜奇动 AMAZING SPORT」；description「阅读奇动关于少年穿着、设计细节与日常探索的故事。」集合页只收录已审核文章。
- **验收：**封面与文章相符；未发布草稿不出现；标题、日期、摘要可由内容数据更新。

#### S02 故事详情 `/stories/{slug}`

- **目标：**提供完整、有记忆点的单篇内容，按语境带回产品。
- **模块顺序：**标题/真实日期/作者 → 大图 → 正文分章 → 场景或细节图片 → 文中对应产品 → 下一篇。
- **关键信息：**原创/授权来源、拍摄与内容背景；涉及功能与奖项同样挂接证据。缺作者信息不编造名字，品牌团队署名也须授权。
- **交互：**可读的长文、适量锚点、普通 URL 分享；无需登录或社交 SDK。
- **CTA：**“了解文中款式”→ 对应详情；无对应款时以“继续探索”→ 故事列表结束。
- **SEO：**title「{故事标题}｜奇动探索故事」；description 使用真实摘要；Article 数据中的作者、发布日期与修改日期和页面一致。
- **验收：**关联商品不串款；手机正文可读；图片不覆盖文字；来源信息可发现；不把库存、折扣放入长期故事内容。

#### W01 购买渠道 `/where-to-buy`

- **目标：**提供易辨认、真实且持续维护的官方购买入口。
- **模块顺序：**官方渠道说明 → 已核实线上店铺 → 已核实线下门店（如有）→ 售前/售后联系方式与服务边界 → 品牌主体信息。
- **关键信息：**平台、店铺全称、归属核验、浏览器 URL、最近复核日期；线下地址、营业时间与联系方式须单独核实，不能由旧门店照片推断。
- **交互：**普通网页链接优先；新窗口须清楚提示，失败时提供复制链接。手机不依赖扫码完成购买；二维码与浏览器目标保持一致。无真实客服链接时不放聊天图标。
- **CTA：**“前往{平台}{店铺全称}”；线下“查看地址”只有在真实地址和地图目标确定后出现。
- **SEO：**title「购买渠道｜奇动 AMAZING SPORT」；description「查找奇动经核实的购买渠道，了解店铺信息与联系方式。」没有完整门店资料不生成 LocalBusiness 数据。
- **验收：**归属由品牌确认且桌面/手机手动打开核查；记录登录墙/唤起 App 等行为；无渠道 URL 是完整 MVP 的发布阻塞，不用空链接代替。

#### U01 隐私、法律信息及 404

- **目标：**明确网站主体、数据处理与服务边界，并在错误路径提供返回方向。
- **模块顺序：**隐私页：主体/适用范围 → 实际收集数据与用途 → 工具与第三方 → 联系/更新日期；法律信息页按部署地域及主体审定；404：简明说明 → 返回首页/系列。
- **交互与 CTA：**可访问的正文与真实联系入口；404 可返回已发布页面，无搜索框假交互。
- **SEO：**「隐私说明｜奇动 AMAZING SPORT」「网站信息｜奇动 AMAZING SPORT」；404 返回真实 404 状态，不列入 sitemap。政策页是否收录按发布方案明确。
- **验收：**政策反映实际实现，不能拿空泛模板充当完成；部署地域、分析/日志服务与主体待 D06 审定后核查适用要求。本 PRD 不作法律合规结论。

### 3.5 工程、真实性与运营约束

- 当前无应用技术栈。阶段 3 可评估用户指定的 Next.js App Router + TypeScript + Tailwind CSS 候选：适合路由、结构化内容、响应式及图片处理；是否采用、部署方式及版本在开工前论证，不在本轮安装或承诺。
- 缺素材时，内部预览使用明确的 editorial 占位及资产 ID。上线不能带伪装成真实产品的图库、生成图或竞品图。无可用主视觉会阻塞首页正式发布。
- 图片/视频优先自身授权素材，保留款式、人体及服装比例；未审核嵌入参数的宣传海报不能通过“只是图片”绕过事实检查。
- 主要内容不依赖动画；尊重 `prefers-reduced-motion`，减少移动设备负担。视频有静帧回退及暂停机制。
- 真实用户性能目标：第 75 百分位 LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1；发布前记录实验室环境与结果，发布后才有资格以真实数据判断目标。
- 暂定内部页面资源预算建议：移动首屏主图约 300 KB 以内、桌面约 500 KB 以内，按画质验证调整并记录；HERO 视频不得成为首屏可读性的必要下载。不将这些建议宣称为已达成指标。
- 配置域名后再生成真实 canonical、OG URL、sitemap 与 robots；预览环境需访问控制，noindex 只负责索引意图，不能代替隐私保护。
- 不在公开仓库/静态目录放完整内部手卡、价格、未授权报告及授权合同。无 API Key、账号或密码写入代码。
- 本轮无部署、推送、外部写入。上线、购买服务和其他重要操作按项目指令另行审批。
